DESKO - SẮP XẾP DESKTOP BẰNG CÁC "FENCE"
==============================================

CÀI ĐẶT
1. Giải nén toàn bộ file zip ra một thư mục.
2. Nhấp đúp setup.bat và làm theo hướng dẫn trên màn hình.
   - Nếu máy chưa có .NET 8 Desktop Runtime, setup sẽ tự tải và cài
     (Windows hỏi quyền quản trị: chọn Yes).
   - Nếu Windows hiện "Windows protected your PC": bấm "More info" -> "Run anyway".
3. Ứng dụng được cài vào %LOCALAPPDATA%\Programs\Desko, có shortcut trong menu Start.
   Lần đầu chạy sẽ có hướng dẫn ngắn và đề nghị tạo sẵn vài fence từ desktop của bạn.

Cài bản mới: chạy setup.bat của bản mới, nó tự tắt bản cũ và cài đè, giữ nguyên các fence.

FENCE CHỨA CHÍNH ICON CỦA DESKTOP
Icon trong fence là icon thật của Windows: mở, chọn, đổi tên (F2), chuột phải, kéo thả,
Ctrl+C / Ctrl+V... đều y như trên desktop. File không bị di chuyển hay ẩn đi, nên File Explorer,
hộp thoại mở / lưu file và trang web khi tải file lên đều thấy đầy đủ thư mục Desktop.
Desko tắt "Auto arrange icons" và "Align icons to grid" của desktop để giữ icon trong fence
(icon ngoài fence vẫn được căn theo lưới); gỡ cài đặt sẽ trả lại như cũ.

SỬ DỤNG
- Tạo fence: giữ chuột phải và kéo một khung trên vùng trống của desktop -> "Tạo Fence tại đây".
- Cho icon vào fence: kéo icon thả vào fence (vào đúng ô bạn thả). Kéo ra desktop để bỏ khỏi fence.
- Thả lên giữa một thư mục trong fence: file vào thẳng thư mục đó.
- Lăn chuột trong fence để cuộn khi có nhiều icon hơn chỗ chứa.
- Nhấp đúp vùng trống desktop: ẩn / hiện tất cả fence và icon.
- Nhấp đúp thanh tiêu đề fence: thu gọn / mở ra (rê chuột vào để xem nhanh).
- Kéo mép fence để đổi kích thước (tự căn vừa số icon).
- Kéo một fence thả lên fence khác: gộp thành các tab.
- Folder Portal: fence hiển thị một thư mục; nhấp đúp thư mục con để duyệt, Backspace để quay lại.
- Chuột phải lên thanh tiêu đề fence: đổi tên, màu, thêm tab, quy tắc tự sắp xếp, xóa fence...

PHÍM TẮT
- Ctrl + Alt + F   Tìm trong mọi fence (Enter mở, Ctrl+Enter chỉ vị trí trong fence)
- Ctrl + Alt + D   Xem desktop (như Win + D)
- Gõ chữ trong Folder Portal   Lọc icon (không cần gõ dấu; Esc để xóa)
- Ctrl + Z         Hoàn tác thao tác với fence (xóa, gộp, tách tab...)

CÀI ĐẶT ỨNG DỤNG
- Mở lại Desko (menu Start) khi nó đang chạy, hoặc chuột phải icon khay -> Cài đặt…
- Mọi thay đổi (nền kính mờ, màu, độ đậm...) áp dụng ngay lên các fence.
- Cỡ icon trong fence là cỡ icon của desktop (View trên menu chuột phải desktop, hoặc Ctrl + lăn chuột).

AN TOÀN DỮ LIỆU
- File KHÔNG bị di chuyển, ẩn hay xóa: chúng vẫn nằm trên Desktop như bình thường.
- Icon của fence đang thu gọn, của tab đang ẩn, hay phần đang cuộn khuất được Desko tạm đặt ra
  ngoài màn hình. Thoát ứng dụng (chuột phải icon khay -> Thoát) thì chúng trở lại desktop,
  kể cả khi ứng dụng bị tắt đột ngột.
- Lưu ý: Ctrl + A trên desktop chọn cả những icon đang được tạm cất đó.
- Xóa fence chỉ gỡ khung, icon vẫn ở lại trên desktop.

GỠ CÀI ĐẶT
Chạy uninstall.bat trong %LOCALAPPDATA%\Programs\Desko
(icon đang cất được trả về, cách sắp xếp icon desktop như trước khi dùng Desko,
bỏ khởi động cùng Windows, xóa ứng dụng).
